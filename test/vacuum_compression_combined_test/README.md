# 음압 모터 2대 + 압박 모터 동시 벤치 시험

이 폴더는 두 음압 블로워와 Makerbase VESC 75100 V2 압박 모터를 동시에 켰을 때의
전원·통신·노이즈를 확인하는 별도 Teensy 4.1 시험입니다. Jetson JSON 프로토콜이나
메인 펌웨어가 아니며 부팅·USB 재연결만으로 모터가 시작되지 않습니다.

압력센서, 리니어센서, 전류센서, 엔코더와 리미트 입력은 읽지 않습니다. 따라서 압박
모터는 **리니어축에서 분리한 무부하 상태로 단단히 고정했을 때만** 구동합니다. 축에
결합한 상태에서는 이 코드를 사용하지 않습니다. 음압으로 장치나 하중을 지탱하지도
않습니다. 독립적인 물리 비상정지와 전원 차단 수단이 반드시 필요합니다.

## 배선

전원을 끈 상태에서 배선하고, 모터 주전류는 Teensy·만능기판·브레드보드를 통과시키지
않습니다.

| 장치 | 신호 | Teensy | 비고 |
|---|---|---:|---|
| 음압 1 | VSP / RUN / EN / ERR | 24 / 25 / 26 / 27 | RUN·ERR은 입력 |
| 음압 2 | VSP / RUN / EN / ERR | 33 / 32 / 37 / 36 | 34/35 사용 금지 |
| VESC COMM #5 | TX → RX7 | 28 | VESC TX/SCL |
| VESC COMM #5 | RX ← TX7 | 29 | VESC RX/SDA |
| 공통 | 신호 GND | GND | 모터 주전류 귀환선과 구분 |

- 음압 드라이버의 FG와 `+5V` 출력은 연결하지 않고 각각 절연합니다.
- 음압 RUN/ERR와 VESC TX가 실제로 0~3.3 V인지 먼저 측정합니다. Teensy GPIO는
  5 V 내성이 없습니다.
- VESC의 5 V/3.3 V 전원 핀은 Teensy에 연결하지 않습니다.
- VESC Tool에서 UART 115200과 자체 command-timeout 정지가 실물에서 동작하는지
  별도로 확인해야 합니다.

## 업로드와 명령

Arduino IDE에서 `vacuum_compression_combined_test.ino`를 열고 보드 `Teensy 4.1`,
USB Type `Serial`로 컴파일·업로드합니다. 시리얼 모니터는 115200 baud, Newline 또는
Both NL & CR입니다.

정상 부팅 뒤 `VESC_FW`와 `STATUS ... link_ok=1,vac_ready=1`을 확인합니다. 첫 자동
왕복은 아래처럼 실행합니다.

```text
STATUS
ARM
ROUNDTRIP 6 6 10 500
STOP
```

`ROUNDTRIP` 인자는 차례로 음압 1 듀티(%), 음압 2 듀티(%), 압박 첫 방향의 signed
duty(%), 한쪽 구동시간(ms)입니다. 위 예시는 두 블로워를 전체 과정 동안 6%로 유지하면서
압박 `+10% 0.5초 → 0 지령 → 최소 0.5초 대기 → -10% 0.5초 → 전체 정지`를 수행합니다.
중간에는 VESC가 ERPM과 duty를 250 ms 동안 0으로 보고해야 반대 방향을 시작하며, 2초
안에 이 조건이 성립하지 않으면 전체 정지합니다. 듀티는 전류(A)가 아니며 회전·음압·축
이동을 보증하지 않습니다.

| 명령 | 동작 |
|---|---|
| `STATUS` | VESC 링크·전류 보고값·블로워 RUN/ERR 원시 상태 표시 |
| `ARM` | 모든 출력을 끈 뒤 VESC 정지 보고와 ERR HIGH 안정 상태 확인 |
| `ROUNDTRIP v1 v2 cp ms` | 압박 첫 방향·정지 대기·반대 방향을 한 명령으로 실행; 음압은 계속 유지 |
| `RUN_ALL v1 v2 cp ms` | 한 방향 동시 구동 진단용 |
| `STOP` / `DISARM` | 블로워 PWM 0·EN LOW 후 VESC 0-current 요청 |
| `CLEAR_ERR` | 양쪽 ERR HIGH 및 VESC 정상 상태가 250 ms 유지된 뒤 로컬 잠금 해제 |
| `HELP` | 문법과 제한 표시 |

현재 코드 제한은 음압 각 1~22%, 압박 절댓값 1~50%, 시간 100~2000 ms입니다. 22%는
사용자가 개별 블로워 약 3 A로 관찰한 시험점이며 정격이나 자동 안전 한계가 아닙니다.
10 A는 파워서플라이의 외부 전류 제한값으로만 사용합니다. 펌웨어는 두 블로워 전류를
읽지 않으므로 VESC 보고값과 합쳐 총전류 10 A를 차단할 수 없습니다.

왕복 시험은 `ROUNDTRIP 6 6 10 500`으로 시작하고, 파워서플라이 표시 전류·전압과 배선 온도를
확인하면서 음압 듀티만 10%, 마지막으로 22%까지 올립니다. 두 블로워가 각각 약 3 A,
압박부가 약 1 A라면 정상상태 단순합은 약 7 A지만 기동전류는 이보다 클 수 있습니다.
전류 제한이 반복 작동하거나 전압이 내려가면 즉시 STOP하고 듀티를 올리지 않습니다.
왕복 명령 하나 안에서는 첫 구간 뒤 코드가 0 보고를 확인하고 방향을 자동으로 바꿉니다.
왕복 전체가 끝난 뒤 다시 실행하려면 `ARM`을 새로 입력해야 합니다. 첫 방향을 반대로
하려면 `ROUNDTRIP 6 6 -10 500`처럼 음수를 사용합니다. 코드의 `reported_zero_stable`은
VESC 통신값일 뿐 실제 축 정지 증명이 아닙니다.

이전에 관찰한 약 3 cm 이동은 듀티만으로 재현되는 위치 명령이 아닙니다. 정·역방향에
같은 듀티와 시간을 써도 마찰·관성·부하 때문에 원점으로 정확히 돌아온다고 볼 수 없습니다.
리니어센서와 리미트를 보류한 이 시험에서는 거리 제어와 원점 복귀 판정을 하지 않습니다.

음압 ERR LOW, VESC 오류·응답 노후화, 명령 파손, USB 단절 또는 시간 만료 시 세 구동
명령을 모두 끕니다. 다만 UART 단선 시 VESC에 STOP을 전달할 수 없고 소프트웨어 정지는
물리 비상정지를 대체하지 않습니다.

## 소프트웨어 검사

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File `
  test/vacuum_compression_combined_test/tests/check_combined_bench.ps1
```

이 검사는 제어 경계값, 오류 잠금, 현재 핀맵과 ADC 미사용을 확인합니다. 실제 전압,
PWM 파형, VESC timeout, 모터 회전·정지, 전류, 온도 또는 노이즈는 검증하지 않습니다.
