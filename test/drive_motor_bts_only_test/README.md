# BTS7960 구동 모터 단독 시험

`drive_motor_bts_only_test.ino`는 Teensy 4.1과 BTS7960으로 구동 모터 한 대를
짧게 정·역회전시키는 무부하 벤치 코드입니다. 엔코더는 초기화하거나 읽지 않습니다.
따라서 회전, 정지, 구속, 방향, 이동거리를 검증할 수 없습니다.

## 배선

| Teensy | 권장 경로 | BTS7960 |
|---:|---|---|
| 7 | 74AHCT125 | RPWM |
| 8 | 74AHCT125 | LPWM |
| 15 | 74AHCT125 | R_EN과 L_EN 모두 |
| GND | 공통 접지 | GND |

BTS `VCC`는 5 V, `B+`/`B-`는 24 V 모터 전원, `M+`/`M-`는 모터에 연결합니다.
Teensy 3.3 V 직결을 5 V `74HC244` 입력이 인식한다고 보장할 수 없습니다.
외부 5 V를 Teensy 15번과 연결하면 안 됩니다.

## 사용

Teensy 4.1, USB Type Serial로 업로드하고 115200 baud, New Line으로 엽니다.

```text
ARM
FWD 10 500
```

역방향은 이전 출력이 끝난 뒤 750 ms 이상 기다리고 새로 ARM합니다.

```text
ARM
REV 10 500
```

`FWD`/`REV` 범위는 10~50%, 100~2000 ms입니다. `STOP`은 PWM 0 뒤 EN LOW,
`DISARM`은 출력 차단과 재ARM을 수행합니다. USB 분리 시에도 출력을 끕니다.

## 제한

- 모터가 움직이지 않아도 지정 시간이 끝날 때까지 출력할 수 있습니다.
- 전류, 엔코더, 리미트, E-stop 보조접점을 읽지 않습니다.
- 물리 전원 차단과 PSU 전류 제한을 준비하고 무부하 고정 상태에서만 사용합니다.
- PWM 비율은 모터 전류 비율이 아닙니다.
- 실물 전압·회전·정지·발열은 이 코드 작성이나 컴파일만으로 검증되지 않습니다.
