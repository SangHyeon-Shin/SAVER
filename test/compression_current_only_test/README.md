# 전류 지령 테스트 — 수동 정지 / 1초 펄스, Teensy 4.1 / VESC

`compression_current_only_test.ino` 하나만 업로드합니다. 추가 라이브러리·보조 헤더는 없습니다.
**벨트·볼스크류에서 분리해 고정한 무부하 모터의 방향 확인용**입니다. 이동부는 기계적으로
지지하고 다른 모터 주전원은 분리합니다. 사람·마네킹 압박에 사용하지 않습니다.

## 연결과 업로드

| 연결 | Teensy |
|---|---|
| VESC COMM RX | **29 / TX7** |
| VESC COMM TX | 기존 **28 / RX7** 유지 가능. 이번 코드는 응답을 읽지 않음 |
| VESC 신호 GND | GND |
| VESC COMM 5V·3.3V | **미연결** |

모터 상선·Hall은 VESC에 둡니다. 모든 Teensy 입력은 0~3.3 V를 지킵니다.
Arduino IDE: **Teensy 4.1 / USB Type Serial**. 시리얼 모니터: **115200 / New Line**.
VESC UART도 115200이어야 합니다. VESC Tool·다른 제어기는 동시에 구동하지 않습니다.

## 명령 — ARM/LIMIT/ZERO/CAL 불필요

아래는 **1 A가 해당 모터·VESC·전원에서 적절함을 확인한 경우의 명령 예시**이지 권장 안전값이 아닙니다.
전원 정격 10 A와 모터 전류 지령은 같은 뜻이 아닙니다.

### 수동 정지 (`RUN`)

2026-10-16 사용자 요청으로 추가했습니다. 업로드 후
`READY,build=current_manual_stop_v3` 안내가 나온 다음 명령을 보냅니다.
대문자 명령과 줄바꿈(New Line)을 사용합니다.

```text
RUN 1
```

양수 1 A를 100ms마다 요청하며 **자동 작동시간 제한 없이** 유지합니다.
멈출 때는 같은 시리얼 모니터에서 아래 명령을 별도 전송합니다.

```text
STOP
```

`STOP`은 0 A 지령이지 제동·기계적 정지 확인이 아닙니다. 운전 중 자리를 비우지 말고,
기구에서 분리한 고정 무부하 모터와 독립 물리 전원 차단을 준비한 시험에서만 사용합니다.
리미트·위치·힘·전류·온도 피드백 보호는 추가하지 않았으므로 압박 기구에 연결해 사용하지 않습니다.
VESC의 검증된 전류·전압·회생·통신 timeout 제한을 끄거나 변경하지 않습니다.

`STATUS`의 `run_mode=MANUAL_STOP`이 수동 유지 중임을 나타냅니다.
이 모드에는 `remaining_ms`를 내보내지 않습니다. 정지 후 자동 재시작하지 않습니다.
반대 방향 전류는 실제 축이 멈춘 것을 확인한 뒤 새로운 `RUN -전류_A`로 요청합니다.

### 기존 1초 펄스 (`PULSE`)

```text
PULSE 1
```

양수 1 A 지령을 현재 파일 설정인 100ms마다 갱신하고, 1초가 되면 0 A를 요청합니다.
`EVENT,PULSE_DONE`은 지령 종료이지 실제 축 정지 확인이 아닙니다.

축이 완전히 멈춘 것을 직접 확인한 뒤 반대 방향을 시험합니다.

```text
PULSE -1
```

전류는 직접 선택합니다. 예를 들어 `PULSE 0.5`는 +0.5 A입니다. 부호와 소수점 이하
최대 세 자리를 허용하며 0, NaN/Inf, 지수·단위·남는 인자는 거부합니다. 잘못된 명령도 정지를 요청합니다.
2026-10-15 사용자 요청으로 기존 15 A 입력 상한만 제거했습니다. 임의의 새 전류 상한을
추가하지 않았고, signed-int32 mA 패킷의 표현 범위와 넘침 검사는 유지합니다. 이 표현 범위는
실제 구동 가능한 전류나 안전 전류가 아닙니다. 모의 시험의 극단 경계값은 실물에 보내지 않습니다.
VESC 자체 전류·전압·회생·timeout 설정은 변경하지 않으며, 입력이 허용되어도 실제로 같은
전류가 흐른다는 뜻은 아닙니다. `PULSE`의 1초 자동 종료와 두 모드의 STOP·오류/USB 단절 정지는 유지했습니다.
부팅·USB 재연결·시간 종료 후 자동 재실행하지 않습니다.

| 명령 | 동작 |
|---|---|
| `RUN 전류_A` | 선택한 부호 있는 전류를 STOP/오류/USB 단절 전까지 계속 요청, 자동 작동시간 제한 없음 |
| `PULSE 전류_A` | 선택한 부호 있는 전류를 1초 동안 요청 |
| `STOP` | 즉시 0 A 요청 |
| `STATUS` | 지령 상태·남은 시간. 실제 측정값 아님 |
| `HELP` | 명령 안내 |

연속 상태 출력은 없습니다. 실행 중 다른 RUN/PULSE를 보내면 정지하며 즉시 반전하지 않습니다.
반전 시험은 반드시 사람이 실제 정지를 확인한 후 별도 명령으로 수행합니다.

## 한계 — 이 코드는 송신만 함

- 위치·속도·전류 피드백, 리미트, 비상정지 보조접점, VESC fault/통신 끊김을 읽지 않습니다.
  `OK`는 Teensy 송신 요청이지 VESC 수신·실행·회전 확인이 아닙니다.
- `PULSE`의 1초는 Teensy가 비영 전류 지령을 보내는 구간입니다. `RUN`에는 그 종료 타이머가 없습니다.
  어느 모드도 관성 이동·통신 지연·실제 정지시간을 보장하지 않습니다.
- STOP/종료/USB 분리/명령 오류/송신 버퍼 부족 시 0 A를 먼저 요청합니다. UART 단선·MCU 정지에서는
  0 A 전달을 보장할 수 없으므로 **VESC 자체의 검증된 timeout과 독립 물리 전원 차단이 필수**입니다.
- 0 A는 브레이크·하중 유지가 아닙니다. 비상정지 해제/짧은 전원 차단을 감지하지 못합니다.
- 부팅에도 0 A를 요청합니다. 다른 프로그램으로 동시에 VESC를 구동하면 안 됩니다.
- 전류/전압/회생/속도 제한은 VESC 설정에서 확인합니다. 이 스케치는 설정을 쓰거나 모터 검출을 하지 않습니다.

현재 소프트웨어는 `tested`(컴파일·모의 USB/UART 검사)로만 검증합니다. 실제 방향, 전류 정확도,
정지·timeout·회생·배선은 미검증입니다. 검증 결과는 `VALIDATION.md`를 확인합니다.

근거: [VESC 공식 COMM_SET_CURRENT](https://github.com/vedderb/bldc/blob/master/comm/commands.c)는
signed int32를 1000으로 나눠 A로 해석합니다. 듀티/RPM 명령과 다릅니다.
