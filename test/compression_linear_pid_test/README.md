# 압박 모터 + 리니어 센서 전류 PID — lm_current_v3

Arduino IDE에서 `compression_linear_pid_test.ino`를 엽니다. **Teensy 4.1 / USB Serial**.
같은 폴더의 `.h`도 필요하며 추가 라이브러리는 없습니다.

사용자가 작동을 확인한 `../lm/sketch_sep16a/sketch_sep16a.ino`와 기존 통합본을 비교했습니다.
LM 원본은 그대로입니다. **LM의 사용자 보고와 이번 수정본의 실물 검증은 다릅니다.**
2026-09-27 사용자가 상·하단 리미트 및 별도 물리 E-stop 미설치를 재확인하여 **구동 잠금을 유지**합니다.
센서 확인·보정·VESC 조회·PREVIEW는 가능하지만 ARM/RUN은 미충족 조건을 거부합니다.
무부하·방호된 연구용 고정 시험대 전용이며 사람·마네킹·스프링 압박/임상용이 아닙니다.

## 비교 결과

| 항목 | 이전 통합본 | LM 기준 수정본 |
|---|---|---|
| 제어 | 위치 PID → 속도/ERPM | **위치 PID → 모터 전류(A)**, SET_CURRENT |
| 기본 목표 | 50mm / 110CPM | **5mm / 10CPM**. 50/110은 요청 문법 상한, 달성 보증 아님 |
| PID | 미설정 속도 단위 | LM .80 / .30 / .020, 전류 단위 |
| 필터 | 위치 LPF 없음 | 위치 10ms·속도 25ms LPF. 안전 검사는 필터 전 위치 |
| 주기 | PID/송신 200Hz | PID 200Hz·전류 송신 50Hz·USB 요약 20Hz |
| 보정 | 파일의 고정 두 점 | **ZERO → CAL 실측 이동거리**, RAM만 사용 |
| 종료 | 정지·복귀 오차 검사 | 기본 정지·0.7mm 복귀 오차 검사. LM의 1.5초 능동 복귀는 선택 기능, 기본 OFF |

LM의 위험 소지가 있는 부분은 그대로 복사하지 않았습니다. 실행 중 TARGET 변경은 정지·거부하고,
NaN/Inf/잘못된 숫자·남는 인자를 거부합니다. 기존 USB 단절·CRC·오래된 VESC 값·20ms 제어 지연
정지를 유지하며, LM처럼 늦어진 dt를 5ms로 바꾸지 않습니다. 안전 입력의 설치/극성을 가정하지
않고 잠금을 유지합니다. 전류 이상도 LM의 100ms 지연 대신 응답에서 초과 확인 시 정지합니다.

기존 속도 PID는 `depth_control.h`에 비교/회귀검사용으로 남겼지만 현재 `.ino`에서는 사용하지
않습니다. 공통 궤적/ADC 표시와 기존 VESC 통신 코드를 재사용합니다. 이전 설명은
`README_commissioning_v2.md`에 보관했습니다. 그 파일은 현재 사용법이 아닙니다.

## 연결 — 기존과 같음

| 신호 | Teensy 핀 | 주의 |
|---|---|---|
| VESC COMM TX / RX | 28 RX7 / 29 TX7 | TX↔RX 교차, 115200 baud |
| VESC 신호 GND | GND | 신호 공통 기준, 대전류 귀환 경로와 분리 |
| VESC COMM 5V / 3.3V | 미연결·절연 | Teensy 전원과 묶지 않음 |
| 리니어 OUT | A16 / 물리 40 | 디지털 16번 아님. 12bit ADC |
| 리니어 VCC / GND | 3.3V / GND | 75mm 10kΩ 모듈의 실제 단자 확인 |
| 상/하 리미트 | 3 / 4 예약 | 미설치, 활성 극성 미확인 |
| E-stop 보조접점 | 6 예약 | 독립 하드웨어 차단 상태 입력, 현재 미설치 |

입력은 0~3.3V를 지킵니다. 모터 상선/Hall은 VESC에 연결합니다. 다른 모터 출력은 초기화하지
않으므로 다른 드라이버의 전원·제어선을 분리합니다. 이 스케치는 **Jetson JSON 펌웨어가 아닙니다**.

## 현재 사용법

시리얼 모니터 115200, New Line 또는 Both NL & CR. 자동 구동은 없습니다.

```text
STATUS
CHECK
TARGET 5 10
PREVIEW 1
STOP
```

PREVIEW는 목표 궤적만 생성합니다. 비영 전류 지령은 없지만 대기 중에도 **0A 요청과 VESC 조회**를
송신하므로 다른 프로그램이 VESC를 구동 중일 때 연결하지 않습니다.
CHECK는 ARM/RUN과 같은 14개 설정 검사입니다. `passed=0`은 미충족입니다.

### ZERO/CAL: 이전 코드와 의미가 바뀜

1. 모터 주전원을 분리하고 축/이동부를 기계적으로 지지합니다. 실제 전원 분리·정지는 코드가 확인하지 못합니다.
2. 센서 끝이 아닌 여유 있는 시작점에 놓고 `ZERO`. 상대 0mm를 잡으며 **이전 보정 비율을 삭제**합니다.
3. 압박 방향으로 **실제로 측정한 거리**만큼 옮긴 후 `CAL 거리_mm`. 20mm 실측했다면 `CAL 20`.
   허용 거리는 5~60mm, ADC 차이 최소 30코드입니다. 정확도 인증은 아닙니다.
4. `CAL_SHOW` 확인 후 중간 위치도 독립 거리와 비교합니다. 요청 깊이는 CAL 거리보다 **작아야** 합니다.
5. 수동으로 시작점에 복귀합니다. 이때 ZERO를 다시 입력하면 보정이 지워집니다. 자동 홈 탐색은 없습니다.

CAL 숫자는 이동 지령이 아니라 실측값입니다. 환산식은
`(raw-zero_raw) × known_mm / (cal_raw-zero_raw)`이고 역방향 ADC도 됩니다.
LM처럼 선형 외삽으로 위치를 표시할 수 있지만 목표는 측정 구간 내로 제한합니다.
soft limit은 각 ZERO에 상대적이므로 시작점을 바꿀 때 기계 여유를 다시 확인해야 합니다.
ADC 0~5 / 4090~4095는 제어에서 거부합니다. 미보정/rail이면 mm는 생략하고 0으로 위장하지 않습니다.
중간 전압에 고정된 단선·손상은 ADC만으로 검출할 수 없습니다.

- `CAL_RESET`: 제어 보정과 진단 수집 기록을 모두 지우고 ARM 해제.
- `CAPTURE 실제좌표_mm`: 기존 200샘플/약 1초 raw 진단, 2초 타임아웃. 원점 허가를 무효화하며
  제어 보정은 자동 적용하지 않습니다. 제어하려면 ZERO/CAL 재실행.
- `CAL_SHOW`: `CONTROL_CAL`은 실제 ZERO/CAL, `CAL_CANDIDATE applied=0`은 별도 CAPTURE 후보입니다.
- USB 재연결/재부팅은 RAM 보정을 지웁니다. 오류는 원점 허가를 무효화하고 자동 재시작하지 않습니다.

## 설정 명령

모두 정지 상태에서만 허용하며 변경하면 ARM이 해제됩니다. **VESC 설정을 쓰지 않습니다.**

| 명령 | 의미 |
|---|---|
| `TARGET 깊이_mm CPM` | 기본 5/10, 문법 상한 50/110 |
| `ILIMIT A` | PID 모터 전류 지령 상한. 기본 6A, LM 문법 범위 1~15A |
| `INLIMIT A` | VESC 입력 전류 절댓값의 감독 정지 한계. 기본 2.8A, LM 문법 범위 .5~10A |
| `GAINS Kp Ki Kd` | 기본 .80/.30/.020. 단위 A/mm, A/(mm·s), A/(mm/s) |
| `MOTORFLIP` | 초기 방향 부호가 검증·설정된 경우 부호 뒤집기. 방향 검증/잠금 해제 기능 아님 |
| `ARM` | 설정·실시간 조건 확인 후 준비. 10초 만료 |
| `RUN [횟수]` | 완전한 왕복 횟수. 기본 1, 최대 20, 시간·추종 한계 별도 적용 |
| `STOP` / `DISARM` | 0A 요청, ARM 해제. 물리 정지/하중 유지 확인 아님 |
| `CLEAR_ERR` | 원인 제거 후 정상 조건 250ms를 확인해 로컬 오류만 해제 |

6A가 항상 흐르는 것이 아니며 INLIMIT는 파워서플라이 전류 설정도 아닙니다. LM의 전원 3A 주석과
사용자의 10A 정격 설명이 달라 정격만으로 한계를 올리지 않았습니다. LM의 15/17/10A,
18~26.5V, FET 80°C는 **사용자 코드 출처 값**이지 검증된 권장 한계가 아닙니다.
`CURRENT_CONTROL_SETTINGS_VERIFIED=false` 등 검토 잠금이 남아 있습니다.

코사인 목표와 오차를 만들고 `Kp×오차 + Ki×적분 − Kd×필터된 측정속도`를 ±ILIMIT로 제한합니다.
포화를 키우는 적분은 멈춥니다. 전류 PID는 힘 센서/힘 제어가 아니며 옛 속도 PID와 게인 단위가
다릅니다. 실제 기구·필터·VESC 지연을 포함한 재튜닝이 필요합니다.

## 구동 전에 필요한 것

`bench_config.h`의 미확인 값은 0/false/−1입니다. 임의로 채우지 않습니다.

- 상·하단 리미트, 독립 E-stop/보조접점 설치 및 극성·단선 시험.
- 실제 거리 보정·기계 여유, 센서 단선/단락 시험, 전류 부호와 압박 방향 확인.
- VESC Hall·전류/전압·회생·timeout/단절 반응, 전원 능력 검증.
- 상대 soft travel, 시작/추종 오차·정지 속도·위치 점프/잡음, 궤적 속도/가속도 한계.
- `MAX_RUN_MS`(최대 30초), 전류 PID/전기적 한계 검토와 최종 벤치 확인.

완료 후에만 `CLEAR_ERR`(필요 시) → 보정/수동 시작점 복귀 → `ARM` → `RUN 1`.
**현재 보호장치 미설치 상태에서는 이 구동 절차를 진행할 준비가 되지 않았습니다.**

종료 오차가 LM의 0.7mm 범위를 넘으면 기본 설정에서 END_POSITION_ERROR로 정지합니다.
`RETURN_TO_ZERO_ENABLED=false`가 기본입니다. 별도로 검토해 true로 설정하면 최대 1.5초
**추가 전류로 0mm 위치를 추종**하며 총 실행 시간 한계에 포함됩니다. 전류 0 유지/자동 홈이 아닙니다.
오류/STOP에는 복귀 없이 0A를 요청합니다. PROFILE_ENDED는 추종 성공·실제 정지 보증이 아닙니다.

**0A 요청은 브레이크·하중 유지·물리 E-stop이 아닙니다.** 수직축 낙하 방지/기계적 지지가 필요합니다.
20Hz 전류 감독은 빠른 VESC 보호를 대체하지 않습니다. 독립 watchdog·이중 센서·힘 보호는 없습니다.

## 검증과 근거

실행 명령과 결과는 `VALIDATION.md`에 기록합니다. 변경은 이 폴더뿐이며 LM 원본·다른 시험·
운용 펌웨어·protocol에는 적용하지 않았습니다. 업로드·실물 시험·커밋·푸시는 하지 않습니다.

[VESC 공식 명령 구현](https://github.com/vedderb/bldc/blob/master/comm/commands.c)에서
SET_CURRENT의 signed int32/1000 A 단위를 확인했습니다. SET_RPM과 다르며 실행 ACK는 아닙니다.
알고리즘·필터·기본값 비교 기준은 사용자 LM 원본입니다.
