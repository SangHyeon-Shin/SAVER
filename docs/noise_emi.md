# 통신·신호 노이즈 분석과 대응

작성 2026-10-05 신상현. 수준: **분석(`assumed`)**. 실물 측정 전이며, 회로와 배선 대부분이
실물 검증 전이다(`docs/hardware_mapping.md`). 아래 대응 가운데 연속 판정 횟수, 지연 상한,
서로 확인 허용 차이 같은 값은 **공학 설정값**이다. 한건민이 실측으로 정하고, 정하기 전에는
비워 둔다. 의학값이 아니며 이 문서에서 숫자를 정하지 않는다.

담당: Teensy 펌웨어와 배선은 한건민(`teensy/`는 한건민 소유), 기구와 케이블 경로는 서정준,
Jetson과 UI는 신상현. 프로토콜 변경이 필요한 항목은 없다.

---

## 1. 노이즈원

| 노이즈원 | 기전 |
|---|---|
| 압박 모터와 드라이버(`I_LIMIT_A` 12 A) | PWM 스위칭, 전류 급변 → 접지 전위 흔들림, 복사 노이즈 |
| 후륜 BTS7960 ×2(24 V) | PWM 스위칭. 브러시 모터면 정류 불꽃 |
| 블로워 BL6561-P ×2(24 V) | 기동 돌입 전류 → 배터리 전압 순간 저하 → 벅 출력과 Jetson 전원 흔들림 |
| 비상정지 주접점 | 유도성 부하 차단 때 전압 튐 |
| 접지 루프 | 모터 귀환 전류가 신호 GND(USB, 센서)로 흐름 |
| 압박 진동(110 회/min) | 커넥터 순간 접촉 불량, 헤드로 가는 이동 케이블 반복 굽힘 |
| 사람 손(시연) | 정전기 |

헤드로 가는 이동 케이블(로드셀, 압박 엔코더, 리미트)은 모터 선 옆에서 반복해서 굽혀지므로
가장 취약하다.

## 2. Jetson–Teensy USB

USB는 패킷마다 CRC와 재전송이 있어 **값이 조용히 틀린 채 전달될 가능성은 낮다**. 현실적인
고장은 **연결 끊김**과 **전원 저하로 인한 재부팅**이다.

| 증상 | 현재 대응(`implemented`, 코드 기준) | 빈틈 |
|---|---|---|
| 끊김, 장치 이름 변경 | VID/PID로 포트 재탐색, 0.5~5 s 지수 백오프 재연결, UI 연결 상태 표시 | 끊긴 횟수와 시각 기록 없음 |
| 깨진 줄 | 버리고 계속(`teensy_serial._read_once`), 512 byte 초과 시 버퍼 비움 | 버린 줄 수를 세지 않음 |
| ACK 유실 | 200 ms, 2회 재전송 뒤 FAULT(2-CM-002) | 재전송 통계 없음 |
| Teensy 재부팅 | `boot_id` 변화 감지, `BOOT_MISMATCH`, 이전 요청 재전송 금지(v1.1) | 재부팅 원인 기록 없음 |
| 오래된 텔레메트리 | 500 ms 넘으면 회색, 정상값으로 쓰지 않음 | — |
| 통신 두절 | Teensy 감시 2 s, 압박 중이 아니면 즉시 FAULT, 압박 중이면 `T_comm` 뒤 정지, 재연결 뒤 자동 재개 없음 | `T_comm` 25 s 펌웨어 반영 전 |
| 소프트웨어 전체 실패 | 물리 비상정지가 USB와 무관하게 모터 전원 차단 | 후륜 차단 미검증(10/7) |

대응

| 담당 | 대응 |
|---|---|
| 한건민 | Teensy `VIN`–`VUSB` 분리 확인(D-33) |
| 한건민 | 스타 접지: 모터 귀환선은 배터리 음극으로 바로, 논리 접지와 분리 |
| 한건민 | **Jetson 전원 경로 확인.** 모터와 같은 배터리라면 별도 벅으로 분리. Jetson Nano는 5 V가 떨어지면 성능 저하나 재부팅 |
| 한건민 | 드라이버 전원 입력 근처에 대용량 콘덴서(블로워 돌입 전류) |
| 한건민 | `Serial.println`이 호스트가 읽지 않을 때 제어 루프를 막지 않는지 확인. 쓰기 전 빈 공간(`availableForWrite`)을 보고 줄 단위로 버림 |
| 한건민 | 재부팅 원인(전압 저하, 감시 리셋)을 `GET_INFO`로 보고(형식은 합의 필요) |
| 서정준·한건민 | USB 케이블 1 m 이하 차폐, 양 끝 페라이트, 모터선과 분리하고 만나면 직각, 커넥터 고정 |
| 신상현 | 링크 품질 기록: 버린 줄, ACK 재전송, FAULT, 재연결, `boot_id` 변화를 세션 기록에 남김 |
| 신상현 | 커널 로그의 USB 끊김 시각을 모터 동작 기록과 함께 남김. Jetson USB 절전 끄기(`usbcore.autosuspend=-1`) |
| 조건부 | 위 대응 뒤에도 끊기면 USB 절연기(풀스피드). Teensy 4.1이 풀스피드로 연결되는지 실물 확인 |

USB에서는 줄 단위 체크섬이 필요 없다. UART 직결로 바꾸면 그때 필요하다(프로토콜 변경).

## 3. Teensy 주변 신호

### 3.1 1순위: 안전 직결 (값이 틀리면 깊이, 힘, 위치, 정지가 틀어짐)

| 경로(핀) | 방식 | 노이즈 때 | 대응 |
|---|---|---|---|
| 압박 엔코더(30/31) | 직교 펄스, 인터럽트 | 펄스를 더 세거나 빠뜨림 → 깊이 오차 누적 | 차폐 꼬임선, 짧게. Schmitt 입력이나 RC 필터. 하드웨어 직교 디코더(QuadEncoder, 30/31 사용 가능 여부 확인). **리니어 센서와 서로 확인해 차이가 크면 고장**. 상단 원점에서 매 회 재기준 |
| 리니어 센서(A16) | 아날로그 | 값 튐 → 깊이 표시와 추종 흔들림 | RC 필터와 평균, 아날로그 접지 분리, 엔코더와 서로 확인 |
| 하단·상단 리미트(3, 4) | 디지털 | 거짓 작동 → 불필요한 정지(3-CU-022), 놓치면 과도 이동 | **평소 닫힌 접점(NC) 배선**: 선이 끊기면 작동으로 판정. RC 필터, 디바운스, 모터선과 다른 다발 |
| 로드셀 NAU7802(Wire1 17/16) | I²C, 헤드 쪽 이동 케이블 | 값 튐 → 힘 상한 거짓 정지, 탐색 반력 오판. 버스 멈춤 | 100 kHz 이하, 풀업 강화, 짧게(길면 I²C 연장 칩). **버스 멈춤 복구(SCL 9펄스)와 시간 초과**. 끊기면 센서 상실로 정지(v1.1). 탐색 판정은 정지 뒤 평균(`drv_avg_ms`) |
| 전류 센서(A17) | 아날로그 | 튐 → 과전류 거짓 정지(래치), 실제 과전류를 놓침 | 필터 + 연속 N회 초과 판정(지연 상한 함께). **드라이버 자체 전류 제한도 켬**(이중 보호) |
| 압력 센서(A8) | 아날로그 | 튐 → 흡착 상실 거짓 정지(3-VU-006), 미달인데 정상 | 이동평균 + 시간 조건(`VAC_ABORT_KPA` 밖에 일정 시간 머물 때만). 기준 게이지와 비교(T1) |
| 압박 드라이버 UART(Serial7 28/29) | TTL 직렬 | 명령 깨짐이나 유실 → 잘못된 동작, 정지 명령 유실 | 드라이버가 VESC라면 패킷 CRC 있음(드라이버 종류 미정). **드라이버 쪽 명령 시간 초과 정지 설정**. 선은 짧게 꼬고 GND 동반. 정지 명령은 아직 미구현(D-45) |
| 주행 엔코더 ×2(11/12, 20/21) | 직교 펄스 | 거리 오차 → 압박 위치가 틀림 | 압박 엔코더와 같은 대책. 좌우 엔코더와 자이로 서로 확인(D-36) |

### 3.2 2순위: 불필요한 정지와 오작동

## 4. Jetson 주변

| 경로 | 노이즈 때 | 대응 |
|---|---|---|
| 터치 입력(USB) | 전원·접지 노이즈 → 누르지 않았는데 눌림, 무반응 | 디스플레이 전원을 깨끗한 5 V로, USB와 HDMI 페라이트. 재개·압박 시작은 장치 상태 검사가 막음(v2.3). 필요하면 길게 누르기 |
| 헤드셋 오디오(HDMI → 모니터 3.5 mm) | 접지 루프 '윙' 소리, PWM 고주파음 | 3.5 mm 접지 루프 차단기, 페라이트 |
| 레이더 MR60BHA2(UART, 형태 미정) | 압박 진동이 호흡 신호를 덮음 | 압박 중 값은 참고 표시만. USB-UART면 2절 USB 대책 |
| 카메라(CSI, 미착수) | 플랫 케이블이 노이즈에 약함 | 짧게, 모터선과 분리 |
| UI ↔ 브리지(WebSocket, 같은 Jetson) | 물리 노이즈 없음 | 연결 대기 화면(D-44) |

## 5. 공통 원칙

1. **안전 쪽으로 판정한다.** 리미트와 비상정지는 NC 배선. 센서 값이 끊기거나 범위를 벗어나면 0으로 대신하지 않고 상실로 처리한다(측정 불가 필드는 생략).
2. **두 신호를 서로 확인한다.** 엔코더와 리니어 센서, 좌우 엔코더와 자이로, 압력 센서와 기준 게이지.
3. **정지 판단은 연속 판정으로 한다.** 한 번 튄 값이 아니라 N회 연속이나 일정 시간 지속. 지연 상한을 같이 정한다.
4. **배선을 나눈다.** 모터 전력선, 디지털 신호선, 아날로그선을 다른 다발로, 만나면 직각. 헤드 이동 케이블은 차폐하고 고정한다.
5. **접지는 한 점에 모은다.** 아날로그 기준을 모터 귀환 전류와 분리한다.

## 6. 확인 시험

| 날짜 | 시험 | 기록 |
|---|---|---|
| 10/7 사전 점검 | 모터를 켰을 때 거짓 리미트, ESTOP, 과전류, 흡착 상실이 뜨는지 | 발생 시각과 그때 동작 |
| 10/8 PID 보완 | 압박 엔코더와 리니어 센서 동시 기록. 오실로스코프가 있으면 엔코더선과 I²C선 파형 | 두 값의 차이 |
| 10/11 벤치(모터 없음) | 30분 연속 20 Hz 통신 | 버린 줄, 재전송, 끊김, 최대 ACK 지연(기준값) |
| 10/12 장치 연결 | 같은 시험을 모터·블로워를 켠 채: 블로워 기동·정지 반복, 압박 왕복, 후륜 PWM 최대, 비상정지 10회 | 위 항목 + 재부팅, 로드셀 튐, I²C 오류, 자이로 검사값 실패 |
| 10/14 G1 | 인터록 점검표 B7, B9, B10, C5~C7, C9 | 점검표 |
| 10/16 리허설 | 시연 중 케이블을 흔들고 손으로 만짐 | 끊김 여부 |

판정 목표(공학 제안값, 팀 합의로 정함): 30분 동안 USB 끊김 0회, Teensy 재부팅 0회,
거짓 정지 0회. 미달이면 2절 대응을 접지 → 케이블 → Jetson 전원 → 절연기 순서로 넣고 다시 시험한다.
