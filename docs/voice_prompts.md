# 음성 안내 문구 초안 v0.4

원본: `ui/src/voice/prompts.json` (이 문서는 그 파일에서 생성). 상태: **한성윤 검토 전**. 작성 2026-10-04, 신상현.

## 원칙

- 화면에 있는 문구를 말로 옮긴다. 새 의학 지시를 만들지 않는다.
- 한 문구는 3초 안팎. 존댓말 명령형. 용어는 화면과 같게 쓰되, 약어는 풀어 쓴다.
- TTS 입력(`say`)에는 숫자와 영문을 쓰지 않는다. 발음대로 한글로 적는다(smoke 시험이 검사). 보이스 태그만 예외다.
- 압박 중(S7)에는 진입 1회만 말한다. 119 상담원 스피커폰 음성과 겹치면 구조자가 혼란스러워한다는 팀 인터뷰 지적을 반영했다.
- AED 화면(X_AED)에서는 진입 안내 1회 뒤 장치 음성을 끈다. AED의 자체 음성 안내가 우선이다.
- 음성은 화면과 경보음을 보조한다. 재생에 실패해도 제어에는 영향이 없다. 음소거와 다시 듣기를 둔다.
- 생성 음성은 AI 생성 콘텐츠다. 사용하면 AI 활용 표기 목록과 결선 발표의 AI 활용 고지에 넣는다.

## 생성 방식 (v0.4)

TTS 생성 방식 v0.4: 모델 2개(Eleven v4, Gemini 3.8 Flash TTS). 각 서비스의 목소리 필터로 목소리 1개를 고른 뒤, 문장 앞에 등급별 보이스 태그 하나만 붙여 만든다. 긴 지시문은 쓰지 않는다. 두 모델에 같은 태그와 문장을 넣는다. 성별은 팀이 정하고 두 모델에 같게 한다.

**목소리 고르는 기준**
- 한국어 원어민, 표준어(서울말). 사투리나 외국어 억양이 없는 목소리
- 차분하고 또렷한 목소리. 밝고 들뜬 목소리, 속삭이는 목소리, 거친 목소리는 고르지 않는다
- 후보 2~3개를 V16 문장으로 들어 보고 1개를 고른다. 5문구 모두 같은 목소리로 만든다
- 고른 목소리 이름(ID)과 필터 값을 meta.txt에 적는다

**ElevenLabs Eleven v4 목소리 필터**

| 필터 | 값 |
|---|---|
| 언어 | Korean (한국어) |
| 카테고리 | 교육용 (후보가 적으면 낭독) |
| 성별 | 여성 또는 남성(팀 결정) |
| 나이 | 젊은 또는 중년 |
| 통지 기간 | 1년 또는 ∞ (전체 문구 재생성과 CO-Show까지 같은 목소리를 쓰기 위함) |
| 맞춤 요금 | 제외 |
| 품질 | 스튜디오 품질 |
| 라이브 모더레이션 | 제외 |

설정: 모델 Eleven v4 (Turbo 아님), 언어 한국어, 속도·안정도 기본값

**Google Gemini 3.8 Flash TTS 목소리 필터**

| 필터 | 값 |
|---|---|
| Gender | Female 또는 Male(팀 결정) |
| Pitch | 가운데 값 (Medium 등) |
| Style | Clear (후보가 적으면 Calm, Firm) |
| Use case | Instructional (후보가 적으면 Digital Assistant, Professional) |

Style에서 Upbeat, Energetic, Witty, Casual, Intimate, Gravelly는 고르지 않는다.

설정: 모델 Gemini 3.8 Flash TTS, 스타일 지시 칸 비워 둠 (태그만 사용), 그 밖 기본값

**보이스 태그 (등급별, 두 모델 공통)**

| 등급 | 태그 | 뜻 |
|---|---|---|
| 안내 | `[calm]` | 차분하고 친절하게. 감정은 중립 |
| 주의 | `[serious]` | 차분하지만 단호하게 |
| 경고 | `[urgent but calm]` | 긴박감을 조금 높이되 소리치거나 겁주지 않음 |

태그는 영어로 둔다(두 모델의 공개 안내가 영어 태그 기준). 문장마다 태그 하나만 맨 앞에 붙인다. 태그가 소리로 읽히면 태그를 빼고 다시 만든 뒤 meta.txt에 적는다.

| 문구 ID | 고른 이유 | 넣을 문장 (태그 포함, 두 모델 같음) |
|---|---|---|
| V16 | 긴급 지시(손 떼기) | `[serious] 환자에게서 모두 손을 떼세요. 화면을 누르면 압박이 시작됩니다.` |
| V25 | 경보(위치 이탈) | `[urgent but calm] 압박 위치가 어긋났습니다. 유도선에 맞춰 조정해 주세요.` |
| V19 | 의학 용어(자발순환) | `[urgent but calm] 자발순환이 의심됩니다. 맥박과 호흡을 확인하세요.` |
| V10 | 영문 약어 읽기(PPG → 피피지) | `[calm] 피피지 센서를 환자의 손가락에 끼워 주세요.` |
| V31 | 숫자 읽기(1초 → 일 초) | `[calm] 일 초 동안, 천천히 숨을 불어넣으세요.` |

- 파일 이름: `모델코드_문구ID.확장자` (`el4` = Eleven v4, `gm38` = Gemini 3.8 Flash TTS. 예: `el4_V16.mp3`, `gm38_V25.wav`).
- 형식은 가능하면 WAV, 안 되면 MP3(128 kbps 이상).
- 모델마다 `모델코드_meta.txt`: 모델 이름, 목소리 이름·ID, 고른 필터 값, 태그를 뺀 문장이 있으면 그 ID, 요금제(무료/유료), 생성 날짜.
- 10개는 무료 체험 범위로 충분하다. 최종 생성은 선정 모델의 상업 이용 조건을 확인한 뒤 한다.

**받은 뒤 (신상현·Claude Code)**
1. 길이·음량·잘림 확인, 음량 맞춤(듣는 크기 차이가 평가를 흔들지 않게).
2. 블라인드 비교 페이지: 모델 이름을 가리고 순서를 섞어 문구별로 1~5점(자연스러움, 또렷함, 긴급 문구 어울림) + 발음 오류 표시. 팀원 각자 평가.
3. 결과로 모델·목소리 확정 → 전체 생성 → UI 연동(화면 진입 시 재생, 음소거·다시 듣기, 파일 없으면 무음).
