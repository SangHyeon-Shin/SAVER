# 음성 안내 문구 초안 v0.10

원본: `ui/src/voice/prompts.json` (이 문서는 그 파일에서 생성). 상태: **한성윤 검토 대기(10/9까지)**. 작성 2026-10-04, 일정 갱신 2026-10-07, 신상현.

## 원칙

- 화면에 있는 문구를 말로 옮긴다. 새 의학 지시를 만들지 않는다.
- 일반인 구조자가 처음 듣고 바로 알아듣는 말만 쓴다. 의학, 공학 용어와 영문 약어는 아래 "쉬운 말" 표대로 풀어 쓰고, 화면 문구도 같은 말로 맞춘다.
- 한 문구는 3초 안팎. 존댓말 명령형.
- 한 화면에 지시 하나. 여러 지시는 화면 안 단계로 나누고, 단계마다 문구 하나를 구조자가 [다음]을 누를 때 말한다(재생 시점 "N단계", D-42).
- 블로워 소리가 커서 구조자는 헤드셋으로 듣는다. 시작 대기(S2)의 첫 단계가 헤드셋 착용이고, 음성은 착용 뒤에만 쓴다. 그 앞 화면 문구(V01~V03)와 착용 안내(V40)는 무음이며 첫 음성은 119 안내(V36)다. 안전핀 뒤(X_PIN 2단계)에서 착용을 다시 확인한다(V41, D-40, D-43).
- 바퀴는 평소 내려가 있고 안전핀을 뽑으면 저절로 올라간다. 바퀴를 내리거나 올리라고 말하지 않는다(D-42).
- TTS 입력(`say`)에는 숫자와 영문을 쓰지 않는다. 발음대로 한글로 적는다(smoke 시험이 검사). 보이스 태그만 예외다.
- 압박 중(S7)에는 진입 1회만 말한다. 119 상담원 스피커폰 음성과 겹치면 구조자가 혼란스러워한다는 팀 인터뷰 지적을 반영했다.
- AED 화면(X_AED)에서는 진입 안내 1회 뒤 장치 음성을 끈다. AED의 자체 음성 안내가 우선이다.
- 음성은 화면과 경보음을 보조한다. 재생에 실패해도 제어에는 영향이 없다. 음소거와 다시 듣기를 둔다.
- 생성 음성은 AI 생성 콘텐츠다. 사용하면 AI 활용 표기 목록과 결선 발표의 AI 활용 고지에 넣는다.

## 쉬운 말

일반인 구조자가 처음 듣고 바로 알아듣는 말만 쓴다. 의학, 공학 용어와 영문 약어는 아래처럼 풀어 쓴다. 뜻이 바뀌면 안 되므로 의학 문구는 한성윤 검토를 받는다. 화면 문구도 같은 말로 맞춘다.

| 쓰지 않는 말 | 바꿔 쓰는 말 |
|---|---|
| AED | 자동심장충격기 |
| 자발순환(ROSC) 의심 | 심장이 다시 뛰는 것 같습니다 |
| 흡착, 음압 고정 | 바닥 고정 |
| 유도선, 정렬 | 초록색 선에 몸을 맞추기 |
| PPG 센서 | 손가락 센서 |
| 튜빙 | 호스 |
| 압박점, 탐색 | 압박 위치, 찾기 |
| EAPD(흉곽 전후 직경) | 가슴 두께 |
| 밀착 | 꼭 맞게 대기 |
| 압박 중단 | 가슴 압박을 멈춘 시간 |

TTS 입력(`say`)에 쓰면 smoke 시험이 실패하는 말: 에이이디, 자발순환, 흡착, 음압, 유도선, 정렬, 피피지, 튜빙, 밀착, 탐색, 압박점, 흉곽, 흉부, 반력, 시피알, 소생

## 생성 방식 (v0.10)

TTS 생성 방식 v0.7: ElevenLabs Eleven v4 하나로 만든다. Voice Library 필터로 목소리 1개를 고르고, 아래 설정을 고정한 뒤, 문장 앞에 등급별 보이스 태그를 붙여(안내는 태그 없음) 문장마다 따로 생성한다. 시험 묶음(6개)으로 설정과 전달 경로를 먼저 확인하고, 목소리 확정(한성윤 목소리 기준 10/7 요청, 확정 10/12)과 한성윤 문구 검토(10/9) 뒤 전체를 만들어 KSME 결선 시연에 쓴다.

| 묶음 | 언제 | 목소리 | 파일 |
|---|---|---|---|
| 시험 묶음 | 10/5 생성 완료 | Salang (calm, clear and warm), 신상현 | 6개 (V10, V36 문장과 태그 조정) |
| 전체 | 10/15 (한성윤 목소리 기준 10/7, 문구 검토 10/9, 목소리 확정 10/12 뒤) | 한성윤 기준으로 10/12 확정 | 35개 (무음 4개, 보류 V19 제외) |
| 결선 시연 | 10/16 리허설에서 확인, 10/23 장치 완성 점검에서 최종 확인 | 전체와 같음 | — |

### 1. 목소리 고르기 (Voices → Library)

| 필터 | 값 |
|---|---|
| 언어 | Korean (한국어) |
| 카테고리 | 교육용 (후보가 적으면 낭독) |
| 성별 | 여성 또는 남성(시험 묶음은 임시) |
| 나이 | 젊은 또는 중년(시험 묶음은 임시) |
| 통지 기간 | 1년 또는 ∞ (CO-Show까지 같은 목소리로 다시 만들 수 있어야 함) |
| 맞춤 요금 | 제외 |
| 품질 | 스튜디오 품질 |
| 라이브 모더레이션 | 제외 |

- 한국어 원어민, 표준어(서울말). 사투리나 외국어 억양이 없는 목소리
- 차분하고 또렷한 목소리. 밝고 들뜬 목소리, 속삭이는 목소리, 거친 목소리는 고르지 않는다
- 후보 2~3개를 미리 듣고, 그중 가장 나은 1~2개로 V16을 한 번 만들어 들어 본 뒤 1개를 고른다
- 성별과 나이는 시험 묶음에서는 임시로 정한다. 전체 생성 때 한성윤 목소리 기준(10/7 요청, 회신 대기)에 맞춘다

### 2. 생성 설정 (모든 문구 공통)

| 항목 | 값 | 이유 |
|---|---|---|
| 모델 | **Eleven v4 (Turbo 아님)** | 파일을 미리 만들어 두므로 응답 속도보다 품질이 우선이다 |
| 안정성 | **50 % (기본값, 시험 묶음에서 쓴 값)** | 처음 안은 약 75 %였으나 시험 묶음을 50 %로 만들었다(파일 이름 s50). 파일 전체가 같은 사람, 같은 말투로 들려야 하므로 나머지도 50 %로 만든다. 파일마다 목소리가 흔들리면 75 %로 올리고 전부 다시 만든다 |
| 유사성 | **기본값 (약 75 %)** | 높이면 원래 녹음의 잡음까지 따라 할 수 있고, 낮추면 파일마다 목소리가 달라질 수 있다 |
| 언어 재설정 | **켬, 한국어** | 읽기 규칙을 한국어로 고정한다. 켰을 때 언어를 고르는 칸이 나오지 않으면 끄고 meta.txt에 적는다 |
| 오디오 효과 | **끔 (필터, 노이즈, 공간, 거리 모두)** | 장치 스피커와 현장 소음이 이미 소리를 흐린다. 잔향과 잡음은 말을 알아듣기 어렵게 하고, 전화 같은 필터는 119 상담원 스피커폰 음성과 헷갈릴 수 있다 |
| 출력 형식 | **MP3 44.1 kHz (128 kbps)** | 말소리에는 충분하고 모든 요금제에서 된다. 앞뒤 무음 정리와 음량 맞춤은 받은 쪽(신상현)이 한다 |
| 그 밖 | **기본값. 파일마다 설정을 바꾸지 않는다** | 설정이 파일마다 다르면 목소리가 달라진다 |

시험 묶음 값(50 %)으로 전체를 만든다. 들어 보고 파일 사이 목소리나 말투가 달라지면 75 %로 올리고 시험 묶음부터 다시 만든다. '창의적인' 쪽으로는 내리지 않는다.

### 3. 보이스 태그

| 등급 | 태그 | 뜻 |
|---|---|---|
| 안내 | (없음) | 태그 없음. 목소리가 이미 차분하고 따뜻하다 |
| 주의 | `[clear]` | 한 마디씩 또렷하게 |
| 경고 | `[firm]` | 단호하게. 소리치거나 겁주지 않는다. 긴박감은 경보음과 화면 색이 맡는다 |

목소리: **Salang** (calm, clear and warm). 시험 묶음(10/5, 신상현)에 쓴 목소리. 목소리 자체가 차분하므로 calm 태그는 거의 쓰지 않는다. 확정은 한성윤 목소리 기준(10/7 요청, 회신 대기) 뒤 10/12.

**calm**: calm은 극도의 침착함이 필요한 문구에만 등급 태그 앞에 붙인다(예: [calm, firm]). 경보음이 함께 나는 화면(위치 이탈 V25, 안전 정지 V26)과 기계가 가슴을 누르기 직전 모두 손을 떼게 하는 문구(V16)다. 그 밖에는 붙이지 않는다(목소리가 이미 차분함).

[serious], [urgent]처럼 긴장을 높이는 태그는 쓰지 않는다. 이미 당황한 구조자의 긴장을 더 키울 수 있다(팀 판단, 한성윤 조사로 확인 예정). 태그는 영어로 문장 맨 앞에 한 번만 두고, 안내 등급은 태그 없이 만든다. 문구에 tag 값이 따로 있으면 그 값을 쓴다(V36: 태그 없음, 시험 묶음 결과). 태그가 소리로 읽히면 다시 만들고, 계속 읽히면 태그를 빼고 만든 뒤 meta.txt에 적는다.

### 4. 만들기와 듣기 확인

들어 보고 확인할 것:

1. 태그가 소리로 읽히지 않는다
2. 발음이 맞다. 특히 일일구, 자동심장충격기, 일 초
3. 앞뒤에 잡음, 숨소리, 잘림이 없다
4. 등급에 맞는 말투다. 경고도 소리치거나 겁주지 않는다
5. 다른 파일과 같은 목소리로 들린다

확인 항목에 걸리면 같은 설정으로 다시 만든다(문구당 3번까지). 그래도 안 되면 가장 나은 것을 보내고 meta.txt의 '남은 문제'에 적는다. 문장은 직접 고치지 않는다. 발음 철자는 신상현이 prompts.json에서, 문구 뜻은 한성윤 검토로 고친다.

### 받은 뒤 (신상현)

- 처리: 받은 파일은 앞 0.05초, 뒤 0.25초 무음만 남기고 자른 뒤(경계 5 ms 페이드) 말소리 평균을 −20 dBFS로 맞춘다. 최고값은 −1 dBFS를 넘기지 않는다. MP3 44.1 kHz 모노 128 kbps로 다시 저장해 ui/public/voice/<ID>.mp3에 둔다. 원본은 저장소에 올리지 않는다.
- 재생: 음성은 헤드셋 착용 뒤에만 쓴다(무음 문구는 재생하지 않음, D-43). 화면에 들어갈 때 그 화면 문구를 말하고(after: 문구는 이어서), 화면이 바뀌면 끊는다. 화면 안 단계(step:N)는 구조자가 다음을 누를 때 앞 문구를 끊고 그 단계 문구를 말한다(S2, S3S4, X_PIN, S12. X_VENT는 자동 진행이라 잇는다). 같은 화면의 사건 음성은 끊지 않고 잇는다. 압박 중(S7)은 진입 1회만, 자동심장충격기 화면(X_AED)은 진입 1회 뒤 경고 V39만. 파일이 없거나 재생이 막히면 조용히 건너뛴다. 헤더에 [다시 듣기]와 소리 끄기 버튼. 규칙 voice/plan.js, 재생 voice/player.js. 키오스크 Chromium은 --autoplay-policy=no-user-gesture-required로 띄운다(jetson_setup.sh).
