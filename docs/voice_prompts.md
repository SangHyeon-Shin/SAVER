# 음성 안내 문구 초안 v0.1

원본: `ui/src/voice/prompts.json` (이 문서는 그 파일에서 생성). 상태: **한성윤 검토 전**. 작성 2026-10-04, 신상현.

## 원칙

- 화면에 있는 문구를 말로 옮긴다. 새 의학 지시를 만들지 않는다.
- 한 문구는 3초 안팎. 존댓말 명령형. 용어는 화면과 같게 쓰되, 약어는 풀어 쓴다.
- TTS 입력(`say`)에는 숫자와 영문을 쓰지 않는다. 발음대로 한글로 적는다(smoke 시험이 검사).
- 압박 중(S7)에는 진입 1회만 말한다. 119 상담원 스피커폰 음성과 겹치면 구조자가 혼란스러워한다는 팀 인터뷰 지적을 반영했다.
- 음성은 화면과 경보음을 보조한다. 재생에 실패해도 제어에는 영향이 없다. 음소거와 다시 듣기를 둔다.
- 생성 음성은 AI 생성 콘텐츠다. 사용하면 AI 활용 표기 목록과 결선 13번 슬라이드에 넣는다.

**공통 조건**
- 모델마다 목소리 1개로 5문구를 모두 만든다. 한국어 원어민 표준어, 성인, 차분하고 또렷한 안내 톤. 속도는 기본값.
- 감정 태그·효과음·배경음은 넣지 않는다. 문장부호를 포함해 위 문장을 그대로 넣는다.
- 형식은 가능하면 WAV, 안 되면 MP3(128 kbps 이상).
- 파일 이름: `모델코드_문구ID.확장자` (예: `el4_V16.mp3`, `gm38_V25.wav`, `mm28_V31.mp3`).
- 모델마다 `모델코드_meta.txt`: 모델 정확한 이름, 목소리 이름·ID, 바꾼 설정, 요금제(무료/유료), 생성 날짜.
- 비교용 15개는 무료 체험 범위로 충분하다(문구 5개, 약 150자). 최종 생성은 선정 모델의 상업 이용 조건을 확인한 뒤 한다.

**받은 뒤 (신상현·Claude Code)**
1. 길이·음량·잘림 확인, 음량 맞춤(듣는 크기 차이가 평가를 흔들지 않게).
2. 블라인드 비교 페이지: 모델 이름을 가리고 순서를 섞어 문구별로 1~5점(자연스러움, 또렷함, 긴급 문구 어울림) + 발음 오류 표시. 팀원 각자 평가.
3. 결과로 모델·목소리 확정 → 35개 전체 생성 → UI 연동(화면 진입 시 재생, 음소거·다시 듣기, 파일 없으면 무음).
