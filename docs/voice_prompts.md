# 음성 안내 문구 초안 v0.5

원본: `ui/src/voice/prompts.json` (이 문서는 그 파일에서 생성). 상태: **한성윤 검토 전**. 작성 2026-10-04, 신상현.

## 원칙

- 화면에 있는 문구를 말로 옮긴다. 새 의학 지시를 만들지 않는다.
- 한 문구는 3초 안팎. 존댓말 명령형. 용어는 화면과 같게 쓰되, 약어는 풀어 쓴다.
- TTS 입력(`say`)에는 숫자와 영문을 쓰지 않는다. 발음대로 한글로 적는다(smoke 시험이 검사). 보이스 태그만 예외다.
- 압박 중(S7)에는 진입 1회만 말한다. 119 상담원 스피커폰 음성과 겹치면 구조자가 혼란스러워한다는 팀 인터뷰 지적을 반영했다.
- AED 화면(X_AED)에서는 진입 안내 1회 뒤 장치 음성을 끈다. AED의 자체 음성 안내가 우선이다.
- 음성은 화면과 경보음을 보조한다. 재생에 실패해도 제어에는 영향이 없다. 음소거와 다시 듣기를 둔다.
- 생성 음성은 AI 생성 콘텐츠다. 사용하면 AI 활용 표기 목록과 결선 발표의 AI 활용 고지에 넣는다.

## 생성 방식 (v0.5)

TTS 생성 방식 v0.5: ElevenLabs Eleven v4 하나로 만든다. Voice Library 필터로 목소리 1개를 고르고, 아래 설정을 고정한 뒤, 문장 앞에 등급별 보이스 태그 하나만 붙여 문장마다 따로 생성한다. 시험 묶음(6개)으로 설정과 전달 경로를 먼저 확인하고, 목소리 확정(한성윤 사용성 1차의 목소리 기준, 10/11)과 문구 검토(10/13) 뒤 전체를 만들어 KSME 결선 시연에 쓴다.

| 묶음 | 언제 | 목소리 | 파일 |
|---|---|---|---|
| 시험 묶음 | 10/5 | 임시 목소리 (위 조건으로 팀이 고름) | 6개 |
| 전체 | 10/15 (목소리 기준 10/11, 목소리 확정 10/12, 문구 검토 10/13 뒤) | 한성윤 기준으로 10/12 확정 | 39개 |
| 결선 시연 | 10/16 리허설에서 장치 스피커로 확인, 이후 UI 동결 | 전체와 같음 | — |

### 1. 목소리 고르기 (Voices → Library)

| 필터 | 값 |
|---|---|
| 언어 | Korean (한국어) |
| 카테고리 | 교육용 (후보가 적으면 낭독) |
| 성별 | 여성 또는 남성(시험 묶음은 임시) |
| 나이 | 젊은 또는 중년(시험 묶음은 임시) |
| 통지 기간 | 1년 또는 ∞ (CO-Show까지 같은 목소리로 다시 만들 수 있어야 함) |
| 맞춤 요금 | 제외 |
| 품질 | 스튜디오 품질 |
| 라이브 모더레이션 | 제외 |

- 한국어 원어민, 표준어(서울말). 사투리나 외국어 억양이 없는 목소리
- 차분하고 또렷한 목소리. 밝고 들뜬 목소리, 속삭이는 목소리, 거친 목소리는 고르지 않는다
- 후보 2~3개를 미리 듣고, 그중 가장 나은 1~2개로 V16을 한 번 만들어 들어 본 뒤 1개를 고른다
- 성별과 나이는 시험 묶음에서는 임시로 정한다. 전체 생성 때 한성윤 사용성 1차(10/11)의 목소리 기준에 맞춘다

### 2. 생성 설정 (모든 문구 공통)

| 항목 | 값 | 이유 |
|---|---|---|
| 모델 | **Eleven v4 (Turbo 아님)** | 파일을 미리 만들어 두므로 응답 속도보다 품질이 우선이다 |
| 안정성 | **가운데와 '견고한' 끝의 중간 (약 75 %)** | 파일 39개가 같은 사람, 같은 말투로 들려야 한다. 높일수록 일관되고, 낮출수록 연기가 커지고 결과가 흔들린다. 끝까지 올리면 단조로워지고 태그가 덜 먹는다 |
| 유사성 | **기본값 (약 75 %)** | 높이면 원래 녹음의 잡음까지 따라 할 수 있고, 낮추면 파일마다 목소리가 달라질 수 있다 |
| 언어 재설정 | **켬, 한국어** | 읽기 규칙을 한국어로 고정한다. 켰을 때 언어를 고르는 칸이 나오지 않으면 끄고 meta.txt에 적는다 |
| 오디오 효과 | **끔 (필터, 노이즈, 공간, 거리 모두)** | 장치 스피커와 현장 소음이 이미 소리를 흐린다. 잔향과 잡음은 말을 알아듣기 어렵게 하고, 전화 같은 필터는 119 상담원 스피커폰 음성과 헷갈릴 수 있다 |
| 출력 형식 | **MP3 44.1 kHz (128 kbps)** | 말소리에는 충분하고 모든 요금제에서 된다. 앞뒤 무음 정리와 음량 맞춤은 받은 쪽(신상현)이 한다 |
| 그 밖 | **기본값. 파일마다 설정을 바꾸지 않는다** | 설정이 파일마다 다르면 목소리가 달라진다 |

시험 묶음에서 세 등급의 말투 차이가 전혀 없거나 기계처럼 단조로우면 안정성을 가운데(기본값)로 내리고 meta.txt에 적는다. '창의적인' 쪽으로는 내리지 않는다. 시험 묶음에서 정한 값으로 전체를 만든다.

### 3. 보이스 태그

| 등급 | 태그 | 뜻 |
|---|---|---|
| 안내 | `[calm]` | 차분하고 친절하게. 감정은 중립 |
| 주의 | `[calm, clear]` | 차분하게, 한 마디씩 또렷하게 |
| 경고 | `[calm, firm]` | 차분하지만 단호하게. 긴박감은 경보음과 화면 색이 맡는다 |

[serious], [urgent]처럼 긴장을 높이는 태그는 쓰지 않는다. 이미 당황한 구조자의 긴장을 더 키울 수 있다(팀 판단, 한성윤 조사로 확인 예정). 태그는 영어로 문장 맨 앞에 한 번만 둔다. 태그가 소리로 읽히면 다시 만들고, 계속 읽히면 태그를 빼고 만든 뒤 meta.txt에 적는다.

### 4. 만들기와 듣기 확인

들어 보고 확인할 것:

1. 태그가 소리로 읽히지 않는다
2. 발음이 맞다. 특히 에이이디, 일일구, 피피지, 자발순환, 일 초
3. 앞뒤에 잡음, 숨소리, 잘림이 없다
4. 등급에 맞는 말투다. 경고도 소리치거나 겁주지 않는다
5. 다른 파일과 같은 목소리로 들린다

확인 항목에 걸리면 같은 설정으로 다시 만든다(문구당 3번까지). 그래도 안 되면 가장 나은 것을 보내고 meta.txt의 '남은 문제'에 적는다. 문장은 직접 고치지 않는다. 발음 철자는 신상현이 prompts.json에서, 문구 뜻은 한성윤 검토로 고친다.

### 5. 보내기

- 문구 ID만 파일 이름으로 쓴다. 예: V16.mp3 (내려받은 파일 이름을 바꾼다)
- 폴더: saver_voice_v0.5_시험 (6개) 또는 saver_voice_v0.5_전체 (39개)
- 폴더에 mp3와 meta.txt를 넣고 zip으로 압축해 Claude Code 대화에 올린다

`meta.txt` 양식:

```
문구판: v0.5
묶음: 시험 6개 / 전체 39개 (하나 지우기)
모델: Eleven v4
목소리 이름: 
목소리 ID: 
목소리 필터: 언어 Korean, 카테고리 __, 성별 __, 나이 __, 통지 기간 __, 맞춤 요금 제외, 품질 스튜디오 품질, 라이브 모더레이션 제외
안정성: 약 75 % (바꿨으면 값과 이유)
유사성: 기본값
언어 재설정: 켬, 한국어 (언어 칸이 없었으면 끔)
오디오 효과: 끔
출력 형식: MP3 44.1 kHz 128 kbps
요금제: 무료 / 유료(이름)
만든 날짜: 2026-10-
만든 사람: 
다시 만든 문구(ID: 횟수): 
태그를 빼고 만든 문구(ID): 
남은 문제(ID: 내용): 
```

### 받은 뒤 (신상현)

1. 파일 이름과 ID, 개수 확인
2. 길이, 앞뒤 무음, 잘림(클리핑), 음량 측정
3. 앞뒤 무음 정리, 파일 사이 음량 맞춤 (목표 크기는 장치 스피커로 들어 보고 정함)
4. 발음 문제는 say 철자를 고쳐 그 ID만 다시 요청
5. 화면 연결: 화면 진입 때 재생, 음소거와 다시 듣기, 파일이 없으면 무음, AED 화면은 진입 1회 뒤 무음
6. 시험 묶음이 통과하면 설정을 고정하고 전체 39개를 요청
7. 10/15 18시까지 연결하지 못하면 KSME 결선은 화면 안내만으로 시연한다(음성은 보조, 제어와 무관)

**요금제와 표기**: 무료 요금제는 비상업 용도로만 쓸 수 있고 ElevenLabs 출처 표기가 필요하다(제3자 요약 기준. 공식 약관 페이지는 확인하지 못함). 대회 시연은 비상업으로 보고 시험 묶음은 무료 요금제로 만든다. 전체 생성 전에 요금제 페이지에서 조건을 확인한다. 쓰게 되면 AI 활용 표기 목록과 발표의 AI 활용 고지에 '음성: ElevenLabs Eleven v4'를 넣는다.
