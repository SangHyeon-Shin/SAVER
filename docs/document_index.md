## 3. 파일 이름 규칙

새 문서를 만들 때 지켜 주세요. 정렬과 검색이 쉬워집니다.

```
W07_신상현_젯슨_적용_범위.pdf      주차는 두 자리 (W7 아님)
S2_특허_03_출원서.pdf              단계_주제_순번
REF_ILCOR_2020_가이드라인.pdf      외부 참고자료는 REF_ 접두어
```

- 공백 대신 밑줄 `_`
- **마침표를 파일명 중간에 쓰지 않습니다.** iOS 에서 확장자가 잘립니다.
- 한글 파일명은 UTF-8. Windows 에서 깨지면 CP949/EUC-KR 로 재인코딩

## 4. 문서를 코드로 옮길 때

**명세 문서의 값을 코드에 직접 하드코딩하지 마세요.**

의학적 임계값은 `AGENTS.md` 규칙에 따라 근거가 확인된 것만 씁니다.
값을 넣을 때는 `W12_한성윤_SAVER_근거추적표_v2.docx` 에 근거를 함께 등록하세요.
근거 없이 들어간 숫자는 최종보고서 심사와 특허 실시가능요건에서 문제가 됩니다.
