## 2. 전원

PCB 회로도 기준.

```
Li-Po 4S (12~16.8 V)
  └─ 외부 Buck Converter → 5 V ─┬─ 제어보드
                                ├─ PCB 내 Buck → 3.3 V → 확장 커넥터
                                └─ 냉각팬
```

- 스타 접지(GND 버스바)
- 5 V 입력에 TVS 다이오드, 벌크 100 µF × 2
- 3.3 V 레일 입출력 커패시터, VDD 디커플링 0.1 µF × 4 + 1 µF × 2
- 테스트 포인트: 3.3 V, GND, ADC, I²C SCL/SDA, UART TX/RX, 1-Wire, 팬 PWM, 모터 PWM

> 8/2 통합시험 때 테스트 포인트에 프로브를 걸면 디버깅이 빨라집니다.

## 3. 음압부

### 압력 센서

| 항목 | 값 | 출처 |
|---|---|---|
| 출력 | 0.5~4.5 V | 이전 코드 변환식 |
| 측정 범위 | 2,500 ~ 700,000 Pa | 〃 |
| 변환식 | `P = 2500 + (V - 0.5) × (700000 - 2500) / 4.0` | 〃 |
| ADC 전단 | R 1.6 kΩ + C 1 µF (RC 필터) | PCB 회로도 |
| 레벨 시프터 | 3.3 V 비호환 해결됨 | 프로젝트 이력 |

> ⚠️ 위 변환식은 12 bit ADC 기준입니다. Teensy 4.1 은 `setup()` 에서
> `analogReadResolution(12)` 를 호출해야 `/4095.0` 이 맞습니다.

### 모터 드라이버 신호

| 신호 | 방향 | 의미 | 프로토콜 연결 |
|---|---|---|---|
| `ERR` | 입력 | LOW → 오류 | `2-VU-007` |
| `RUN` | 입력 | LOW → 동작 중 | telemetry |
| `EN` | 출력 | LOW → 긴급 정지 | `motorsOff()` |
| `VSP` | 출력 | 속도 지령 PWM (0~3.3 V → 5 V 변환) | 내부 |
| `FG` | 입력 | 속도 피드백 펄스 | telemetry |

### 목표값 (확인 필요)

| 항목 | 후보값 | 출처 | 상태 |
|---|---|---|---|
| 목표 음압 | **-30.0 kPa** | 이전 코드 `targetPressure = 30000` | 확정 여부 미확인 |
| 허용 오차 | ±0.5 kPa | 이전 코드 `tolerance = 500` | 〃 |
| 재시도 | 3회, 500 ms 간격 | 이전 코드 | 〃 |
| 흡착 면적 | 300 × 300 mm × 2 | 설계서 | 확정 |

## 6. 구동계 (바퀴) — ★ 프로토콜에 명령 없음

이전 코드에 `moveMotorPin1~4` 가 있습니다.
UI 화면 02(바퀴 내리기)·03(환자에게 이동)에 대응하는 것으로 보이는데,
**현재 프로토콜에 이동 관련 명령이 하나도 없습니다.**

UI 화면 03 은 "환자 위치로 끌고 이동해 주세요"로 **사용자가 끄는** 흐름입니다.
그렇다면 모터 4개는 바퀴 전개용인지, 자율 이동용인지 확인이 필요합니다.

**미확정 (명세 §11-8).** 명령이 필요하다면 `WHEELS_DEPLOY` / `WHEELS_RETRACT`
정도가 후보이지만, **추측으로 만들지 않습니다.**
