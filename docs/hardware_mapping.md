### Teensy 4.1 핀 배정

단일 기준은 `teensy/pinmap.h` 입니다. 아래 표와 코드가 다르면 코드 변경 전에 둘을
함께 고칩니다.

| 구분 | 신호 | Teensy 4.1 핀 | 선택 근거 |
|---|---|---:|---|
| PWM | 압박 모터 VSP | `51` (하단 SMT) | `FlexPWM3_3_B`; EN 50과 인접하고 독립 주파수 그룹 |
| PWM | 음압 모터 VSP | `54` (하단 SMT) | `FlexPWM3_0_A`; EN 53과 인접하고 독립 주파수 그룹 |
| PWM | 냉각팬 | `5` | `FlexPWM2_1_A`; 상단 핀의 세 번째 독립 주파수 그룹 |
| 출력 | 압박 모터 EN | `50` (하단 SMT) | VSP 51과 인접한 압박 드라이버 배선 |
| 출력 | 음압 모터 EN | `53` (하단 SMT) | VSP 54와 인접한 음압 드라이버 배선 |
| 입력 | 음압 ERR | `48` (하단 SMT) | RUN 49와 묶은 드라이버 상태 배선 |
| 입력 | 음압 RUN | `49` (하단 SMT) | ERR 48과 묶은 드라이버 상태 배선 |
| 입력 | 리미트 상 | `3` | 하단 리미트 4와 인접한 브레드보드 핀 |
| 입력 | 리미트 하 | `4` | 상단 리미트 3과 인접한 브레드보드 핀 |
| 입력 | E-stop 상태 | `6` | 바로 접근 가능한 전용 브레드보드 안전 입력 |
| 인터럽트 | 엔코더 A | `30` | B상 31과 인접한 브레드보드 인터럽트 핀 |
| 인터럽트 | 엔코더 B | `31` | A상 30과 인접한 브레드보드 인터럽트 핀 |
| 인터럽트 | 홀 센서 | `37` | 브레드보드에서 접근 가능한 인터럽트 핀 |
| 인터럽트 | 음압 FG | `38` | 브레드보드에서 접근 가능한 펄스 입력 핀 |
| ADC | 압력 | `A8` / `22` | 기본 Serial·Wire·SPI와 겹치지 않는 ADC 입력 |
| ADC | 로드셀 | `A9` / `23` | 압력 ADC와 인접한 독립 ADC 입력 |
| ADC | 리니어 변위 | `A16` / `40` | 예약 버스와 겹치지 않는 ADC 입력 |
| ADC | 모터 전류 | `A17` / `41` | A16과 인접한 독립 ADC 입력 |
| I²C | MAX30102 SDA | `18` | 기본 `Wire` SDA |
| I²C | MAX30102 SCL | `19` | 기본 `Wire` SCL |
| 1-Wire | DS18B20 | `9` | 브레드보드 GPIO; 기본 Serial·Wire·SPI 핀 보존 |

PWM 그룹은 Teensyduino 1.62.0 `cores/teensy4/pwm.c`의 매핑을 기준으로 했습니다.
핀 51/54/5는 각각 `FlexPWM3_3`, `FlexPWM3_0`, `FlexPWM2_1`이므로
`analogWriteFrequency()`를 서로 독립적으로 설정할 수 있습니다.

기본/canonical 버스 핀:

- `Serial1~8`: `0/1`, `7/8`, `15/14`, `16/17`, `21/20`, `25/24`, `28/29`, `34/35`
- MAX30102 `Wire`: SDA `18`, SCL `19`
- `Wire1`: SDA/SCL `17/16`, `Wire2`: SDA/SCL `25/24`
- `SPI`: `10/11/12/13`, `SPI1`: `0/1/26/27`, `SPI2`: `42/43/44/45`

위 기본/canonical 경로는 모두 보존합니다. 다만 하단 핀 48/49/50/53/54의 대체
Serial/SPI mux 경로는 사용하지 못합니다.

> **실물 배선 전제:** 핀 48~54는 외곽 브레드보드 헤더가 아니라 보드 하단 SMT
> 패드입니다. 선택형 QSPI PSRAM/플래시가 미실장인 보드에서만 이 배정을 쓰며,
> Teensy를 브레드보드에 꽂기 전에 48/49/50/51/53/54에 리드선을 납땜합니다.
> 핀 52는 예비입니다. 핀 42~47은 microSD SDIO이므로 건드리지 않습니다.

즉시 배선 시 전기 조건:

- Teensy 4.1 GPIO와 ADC는 **3.3 V 전용이며 5 V tolerant가 아닙니다.** ERR/RUN/FG,
  엔코더, 홀, 리미트, E-stop 신호가 3.3 V를 넘으면 레벨 변환 또는 절연 후 연결합니다.
- 0.5~4.5 V 압력센서는 A8에 직결하지 않고 3.3 V 이하로 제한하는 전단을 거칩니다.
- DS18B20 데이터(핀 9)는 4.7 kOhm으로 3.3 V에 풀업합니다. MAX30102 SDA/SCL의
  풀업도 모듈 내장 여부를 확인하고 반드시 3.3 V 기준으로 둡니다.
- EN/VSP/팬 핀은 부하를 직접 구동하지 않고 드라이버 입력에만 연결합니다. MCU 리셋
  중에도 모터가 꺼지도록 EN의 하드웨어 disable 바이어스를 드라이버 쪽에 둡니다.

## 2. 전원

PCB 회로도 기준.

```
Li-Po 4S (12~16.8 V)
  └─ 외부 Buck Converter → 5 V ─┬─ 제어보드
                                ├─ PCB 내 Buck → 3.3 V → 확장 커넥터
                                └─ 냉각팬
```

- 스타 접지(GND 버스바)
- 5 V 입력에 TVS 다이오드, 벌크 100 µF × 2
- 3.3 V 레일 입출력 커패시터, VDD 디커플링 0.1 µF × 4 + 1 µF × 2
- 테스트 포인트: 3.3 V, GND, ADC, I²C SCL/SDA, UART TX/RX, 1-Wire, 팬 PWM, 모터 PWM

> 8/2 통합시험 때 테스트 포인트에 프로브를 걸면 디버깅이 빨라집니다.

## 3. 음압부

### 압력 센서

| 항목 | 값 | 출처 |
|---|---|---|
| 출력 | 0.5~4.5 V | 이전 코드 변환식 |
| 측정 범위 | 2,500 ~ 700,000 Pa | 〃 |
| 변환식 | `P = 2500 + (V - 0.5) × (700000 - 2500) / 4.0` | 〃 |
| ADC 전단 | R 1.6 kΩ + C 1 µF (RC 필터) | PCB 회로도 |
| 레벨 시프터 | 3.3 V 비호환 해결됨 | 프로젝트 이력 |

> ⚠️ 위 변환식은 12 bit ADC 기준입니다. Teensy 4.1 은 `setup()` 에서
> `analogReadResolution(12)` 를 호출해야 `/4095.0` 이 맞습니다.

### 모터 드라이버 신호

| 신호 | 방향 | 의미 | 프로토콜 연결 |
|---|---|---|---|
| `ERR` | 입력 | LOW → 오류 | `2-VU-007` |
| `RUN` | 입력 | LOW → 동작 중 | telemetry |
| `EN` | 출력 | LOW → 긴급 정지 | `motorsOff()` |
| `VSP` | 출력 | 속도 지령 PWM (0~3.3 V → 5 V 변환) | 내부 |
| `FG` | 입력 | 속도 피드백 펄스 | telemetry |

### 목표값 (확인 필요)

| 항목 | 후보값 | 출처 | 상태 |
|---|---|---|---|
| 목표 음압 | **-30.0 kPa** | 이전 코드 `targetPressure = 30000` | 확정 여부 미확인 |
| 허용 오차 | ±0.5 kPa | 이전 코드 `tolerance = 500` | 〃 |
| 재시도 | 3회, 500 ms 간격 | 이전 코드 | 〃 |
| 흡착 면적 | 300 × 300 mm × 2 | 설계서 | 확정 |

## 6. 구동계 (바퀴) — ★ 프로토콜에 명령 없음

이전 코드에 `moveMotorPin1~4` 가 있습니다.
UI 화면 02(바퀴 내리기)·03(환자에게 이동)에 대응하는 것으로 보이는데,
**현재 프로토콜에 이동 관련 명령이 하나도 없습니다.**

UI 화면 03 은 "환자 위치로 끌고 이동해 주세요"로 **사용자가 끄는** 흐름입니다.
그렇다면 모터 4개는 바퀴 전개용인지, 자율 이동용인지 확인이 필요합니다.

**미확정 (명세 §11-8).** 명령이 필요하다면 `WHEELS_DEPLOY` / `WHEELS_RETRACT`
정도가 후보이지만, **추측으로 만들지 않습니다.**
