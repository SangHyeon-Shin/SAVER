## 1. 무엇을 만드는가

**SAVER** — 지능형 압박점 자동탐색 기반 음압 고정식 CPR 시스템

기존 기계식 CPR 장치의 두 가지 문제를 푼 것이 핵심입니다.

| 문제 | SAVER 의 접근 |
|---|---|
| 장치가 흉부에서 밀려남 | **음압 흡착으로 바닥에 고정** (300×300 mm × 2) |
| 압박점을 사람이 찾아야 함 | **강성 매핑으로 검상돌기 위치를 자동 탐색** |
| 환자마다 흉부 강성이 다름 | **환자 적응형 깊이 제어** |

음압 목표값을 비롯한 확정값은 `docs/PROJECT_STATE.md` §2 를 보십시오.
여기에 옮겨 적지 않습니다.

### 알고리즘 5종

1. 중앙 정렬
2. 강성 매핑 기반 압박점 탐색 (검상돌기 식별)
3. 시험 압박
4. 적응 제어 — 상세는 private 저장소 `SAVER-docs`
5. 적응 필터링 기반 ROSC 추정

### 8/1~8/7 우선순위

하드웨어를 만질 수 있는 시간은 이 7일뿐입니다. 코드는 그 뒤에도 쓸 수 있습니다.
**하드웨어가 있어야만 되는 일에 하드웨어 시간을 씁니다.**

| 날짜 | 핵심 |
|---|---|
| 8/1 | 3D 출력 개시(집), 젯슨 환경 조사 |
| 8/2 | **Teensy 통신 (모터 전원 분리 상태)** |
| 8/3 | 조립 시작, 단계별 사진 촬영 |
| 8/4 | 조립 완료, 무부하 구동, 음압부 측정 |
| 8/5 | **★ 압박부 실측** — 깊이·속도·힘·전류 |
| 8/6 | 통합 1회, 고장 주입, 시연 영상 |
| 8/7 | 동결·백업 (교수님 미팅) |

**반드시 확보할 것 4가지**

1. 압박부 실측 데이터 + 예측값 비교표
2. 음압부·레이더 원시 로그
3. 고장 상황 로그 (E-stop, 과전류, 통신 두절)
4. 통합 시연 영상

현재 보고서의 수치가 전부 **설계값**입니다. 실측 데이터가 최종보고서·논문
실시예를 동시에 뒷받침하므로, 8/5 가 이번 주에서 가장 중요한 하루입니다.

**이번 주에 하지 않는 것**: 카메라 AI, 레이더 판단 알고리즘, PID 최종 튜닝,
ROSC 자동 판정. 전부 녹화 데이터로 나중에 됩니다.

### 에이전트를 쓸 때

- **큰 작업을 한 번에 시키지 않습니다.** 프로토콜 → 모의 장치 → 상태머신 → UI
  순서로 쪼개세요. 한꺼번에 시키면 오류 원인을 분리할 수 없습니다.
- **실물 장비가 필요한 부분은 에이전트가 대신할 수 없습니다.**
  Codex 도 Claude Code 도 모터·센서를 못 봅니다. 실기 앞에서 값을 찍어보며
  다듬는 편이 빠릅니다.
- 전면 재작성보다 **정확한 부분 수정**을 요구하세요.

## 5. 개발 환경

| 대상 | 환경 |
|---|---|
| Jetson Nano (2019) | JetPack 4.6.x, Ubuntu 18.04, **Python 3.6** |
| Teensy 4.1 | Arduino IDE + Teensyduino |
| UI | React 18 + Vite (PC 에서 빌드 → 젯슨에 정적 파일 복사) |
| 해석 | MATLAB/Simulink, ANSYS |

**젯슨에서 빌드하지 않습니다.** 18.04 에서 Vite 가 돌지 않습니다.
PC 에서 `npm run build` 한 `dist/` 만 복사합니다.

`websockets` 는 **9.1 로 고정**합니다. 최신 버전은 Python 3.6 에 설치되지 않습니다.

## 6. 자주 막히는 곳

| 증상 | 원인 |
|---|---|
| 젯슨이 모터 근처에서 리셋 | 마이크로USB 전원. **5 V 4 A 배럴잭 + J48 점퍼** 필수 |
| 백그라운드 `&` 로 띄운 프로세스가 멈춤 | 터미널 stdin 읽기 → SIGTTIN. `< /dev/null` 붙이거나 터미널 분리 |
| 시리얼로 보낸 줄이 잘림 | 논블로킹 부분 쓰기. 다 나갈 때까지 반복해야 함 |
| Codespaces 포트 접속 401 | 서버가 안 떠 있거나 포트 비공개 |
| 원격 데스크톱에서 Chromium GPU 오류 | `--disable-gpu`. 실기 로컬 세션에서는 필요 없음 |
